# План по этапам

Каждый этап заканчивается работающим приложением (сборка + `npm test` + офлайн-прогон `npm run cli -- --mock`).

## ✅ Этап 0 — архитектура
Платформенная абстракция, адаптеры провайдеров, модель данных, SQLite, keychain, CI. См. `ARCHITECTURE.md`.

## ✅ Этап 1 — MVP (готово)
«Что если…» 9:16 → идеи (Claude) → сценарий (Claude) → раскадровка (Claude) → картинки (OpenAI / Flux / SD локально) → озвучка (ElevenLabs / OpenAI TTS) → субтитры (тайминг ElevenLabs/Whisper, TikTok-караоке) → рендер MP4 (Ken Burns, FFmpeg).
Плюс уже сейчас: все 4 соотношения сторон, пресеты длительности 15 с–10 мин, 8 встроенных форматов + свои форматы, ручной/авто режим, редактор сцен с перегенерацией одного кадра/озвучки, калькулятор стоимости и бюджет, кэш, ретраи и ресюм, логи и прогресс, редактируемые промпты, тёмная/светлая тема, RU/EN, горячие клавиши, SRT-экспорт, автообновления (Tauri updater).

## Этап 2 — производство
- Видео-клипы: адаптеры Kling, Luma (через fal.ai), Runway, Veo в `providers/video/`; смешанный таймлайн «картинка/клип».
- Музыка и SFX: библиотека + генерация (ElevenLabs Music/SFX), ducking уже есть в рендере.
- Шаг 9 «Метаданные» (схема `MetadataSchema` готова) и шаг 10 «Обложка 1280×720» (картинка + крупный текст через Remotion/FFmpeg drawtext).
- Переходы (xfade), эмодзи в субтитрах.
- Remotion: анимированные титры и шаблоны (рендер через `@remotion/renderer` в Node-сайдкаре).
- Пакетный режим: таблица `queue`, N видео за ночь, пауза/возобновление.
- Сплит-скрин и «Reddit на фоне геймплея» (layout `split`).
- Бренд-кит: шрифты, цвета, логотип, вотермарка, интро/аутро.

## Этап 3 — рост
- Серии: персонаж/стиль/голос между видео (референсы + seed).
- Рекламные вставки с библиотекой рекламодателей.
- Мультиязычность: перевод сценария и переозвучка одной кнопкой.
- Анализ трендов по ссылке (транскрипт → структура-аналог).
- Нарезка Shorts из длинного 16:9 с авто-рефреймингом.
- Автопостинг YouTube Data API / TikTok Content Posting API, календарь, отложенная публикация.
- Аналитика просмотров и удержания + рекомендации Claude.
- Проверка контента (правила платформ, музыка).
- Экспорт проекта целиком для CapCut/Premiere (сценарий, ассеты, SRT, EDL/XML).
